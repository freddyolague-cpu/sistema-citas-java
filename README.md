# Sistema de Administración de Citas

Proyecto desarrollado en Java para simular un sistema de administración de citas de un consultorio clínico.

El sistema permitirá registrar doctores y pacientes, crear citas médicas, relacionar cada cita con un doctor y un paciente, y controlar el acceso mediante administradores.

## Instalación y configuración

El proyecto está desarrollado utilizando Java.

Para ejecutar el programa se requiere:

- Java JDK 11 o superior.
- Un entorno que permita compilar y ejecutar aplicaciones Java.
- Acceso a los archivos del proyecto.
- GitHub para el almacenamiento y control de versiones del código fuente.

Para esta evidencia se utiliza un entorno de desarrollo Java en línea, lo que permite compilar y ejecutar el programa directamente desde un navegador web sin requerir una instalación local.

## Uso del programa

El sistema de administración de citas permitirá realizar las siguientes operaciones:

1. Iniciar sesión mediante un identificador y contraseña de administrador.
2. Registrar doctores con identificador único, nombre completo y especialidad.
3. Registrar pacientes con identificador único y nombre completo.
4. Crear citas indicando identificador, fecha, hora y motivo.
5. Relacionar cada cita con un doctor y un paciente.
6. Consultar la información registrada.
7. Mantener almacenada la información utilizada por el sistema.
